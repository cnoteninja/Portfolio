🛠️ Field IT Toolkit

I'm Christopher McMickens, an IT field technician. These are the open-source tools I built to do the job faster — every one below runs a live demo on sample data, no install needed.

All demos run on synthetic sample data in your browser. Nothing here touches a real network.

AD Onboarder

PowerShell · Active Directory

Onboard a new hire in seconds instead of 20 minutes of clicking through ADUC — bulk CSV import, template-based group copy, safe offboarding with rehire backups, and a stale-account sweeper that catches dormant logins before attackers do.

Live demo Source on GitHub

Printer Auditor

Python · SNMP

Know which printers need toner before users complain. Audits the whole fleet over SNMP (no dependencies), predicts days-until-empty per cartridge, and emails you a morning digest with a reorder list.

Live demo Source on GitHub

Speedtest Logger

Python · Monitoring

Document ISP performance over time: scheduled speed tests, outage detection with uptime %, degradation alerts — and a complaint-letter generator that turns your data into a support ticket they can't ignore.

Live demo Source on GitHub

Wi-Fi Site Survey

Python · Wireless

Walk a site with a laptop and hand the client a coverage report: signal-strength heatmap overlaid on their floor plan, weak-spot callouts, channel congestion, and before/after comparisons after you fix things.

Survey demo Compare demo Source on GitHub

Site Readiness

Python · Field deployments

One command on-site, one client-ready handoff report: internet quality, DNS, latency, and VoIP readiness with MOS scoring — topped with a plain-English executive summary and "how to fix it" for every failure.
